# Uber Ride Analytics Dashboard

Project Title 

Uber Ride Analytics Dashboard | Power BI

📌 Short Description

An interactive Uber Ride Analytics Dashboard built using Microsoft Power BI to analyze ride bookings, revenue, distance, vehicle types, and customer/driver ratings. The dashboard provides a clear view of business performance through interactive KPIs, charts, and visualizations, allowing users to identify trends and compare ride performance across different months and vehicle categories.

🛠️ Tech Stack

- Microsoft Power BI – Dashboard development and data visualization
- Power Query – Data cleaning and transformation
- DAX (Data Analysis Expressions) – Measures, KPIs, and calculations
- Microsoft Excel / CSV – Data handling

📊 Data Source [kaggle]

The dataset was sourced from Kaggle and contains Uber ride-related information such as:

- Booking status
- Vehicle type
- Ride distance
- Revenue
- Customer ratings
- Driver ratings
- Booking/ride information
- Monthly ride performance

✨ Features & Highlights
📌 Key Performance Indicators

The dashboard displays important business metrics such as:

- 93K+ Completed Bookings
- 57K+ Lost Bookings
- 52M Revenue
- 2.51M Total Distance
- 24.64 Average Distance

📈 Monthly & Quarterly Analysis

- Monthly trend of completed bookings
- Monthly revenue analysis
- Option to switch between Month and Quarter
- Helps identify changes in ride demand and revenue over time

🚗 Vehicle Type Analysis
 Revenue is analyzed across different vehicle categories, including:

- Auto
- Bike
- Go Mini
- Go Sedan
- Premier
- Uber XL

⭐ Rating Analysis
The dashboard tracks:

- Average Customer Rating – 4.40
- Average Driver Rating – 4.23

This helps evaluate the overall quality of the Uber ride experience.

🔄 Ride Status Analysis
Visual representation of:

- Completed rides
- Cancelled rides
- Incomplete rides

This provides an overview of successful and unsuccessful bookings.

🎨 Interactive Dashboard

- Interactive navigation
- Vehicle-type selection
- KPI cards
- Donut charts
- Line charts
- Column charts
- Rating cards
- Month/Quarter toggle
- Clean and user-friendly UI

🎯 Project Objective

  The main objective of this project is to transform raw Uber ride data into meaningful business insights using Power BI and   help understand ride performance, revenue trends, vehicle-category performance, booking status, and customer/driver          satisfaction.
